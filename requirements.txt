# labelcheck runtime dependencies — the complete, hash-pinned dependency closure.
#
# Install exactly this and nothing else:
#
#     pip install --no-deps --require-hashes -r requirements.txt
#
# Two things about that command are deliberate.
#
# --no-deps: rapidocr declares a hard dependency on `opencv-python`, which bundles the GUI
#   (Qt/GTK) stack that a headless server has no use for. This file pins
#   `opencv-python-headless` instead — it provides the same `cv2` module — and resolves the
#   whole tree here, so pip never re-derives it and `opencv-python` is never installed.
#   Every transitive package is listed below with its own hash for that reason.
#
# --require-hashes: every artefact is verified by SHA-256 before it is unpacked. Where two
#   hashes are listed, they are the Linux (manylinux x86_64, the deploy box) and macOS
#   (development) wheels of the same version; pip accepts an artefact matching either.
#
# One package cannot be a wheel: antlr4-python3-runtime 4.9.3, pinned by omegaconf 2.3.1
# (rapidocr's config loader), publishes an sdist only — so `--only-binary :all:` cannot be
# used for the whole file. It is pure Python and builds without a compiler, but pip's build
# isolation does need setuptools, which it fetches from the index. Installing from a local
# wheelhouse with --no-index therefore needs a setuptools wheel alongside; that is the only
# thing in this file that is not satisfied by the pinned artefacts alone. Verified both
# ways, 2026-08-04. Everything else is wheels only.
#
# Versions are exactly the ones every measurement in internal/ARCHITECTURE.md was taken on.
# Development tools (ruff, pytest) are pinned in the Makefile, not here — they are not
# installed on the deploy box.
